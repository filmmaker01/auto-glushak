# GLUSHAK — лендинг мастерской выхлопных систем

Продакшн: **https://auto-glushak.vercel.app**

Vite + ванильный JS, GSAP (ScrollTrigger) и Lenis. Шрифты Unbounded и Onest стоят локально через npm.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://127.0.0.1:5173.

## Сборка

```bash
npm run build
npm run preview
```

Готовая статика попадает в `dist/`, `preview` поднимает её на http://127.0.0.1:4173.

## Публикация на Vercel

1. Создайте пустой репозиторий на GitHub (без README и .gitignore) и залейте проект:

   ```bash
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```

2. На vercel.com: **Add New → Project → Import** этого репозитория.
3. Настройки менять не нужно — они зафиксированы в `vercel.json`: фреймворк Vite, установка `npm ci`, сборка `npm run build`, выдача из `dist`. Версия Node (22.x) берётся из `engines` в `package.json`. Переменных окружения нет.
4. **Deploy.** Дальше каждый push в `main` публикуется автоматически, а ветки и pull request'ы получают preview-ссылки.
