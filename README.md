# KOR.TEAM (Кор & Тим) — лендинг мастерской выхлопных систем

Слоган: «Звук, от которого оборачиваются.»

Продакшн: **https://auto-glushak.vercel.app**

Vite + ванильный JS, GSAP (ScrollTrigger) и Lenis. Шрифты Unbounded и Onest стоят локально через npm.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://127.0.0.1:5173.

## Сборка

```bash
npm run build
npm run preview
```

Готовая статика попадает в `dist/`, `preview` поднимает её на http://127.0.0.1:4173.

## Публикация на Vercel

1. Создайте пустой репозиторий на GitHub (без README и .gitignore) и залейте проект:

   ```bash
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```

2. На vercel.com: **Add New → Project → Import** этого репозитория.
3. Настройки менять не нужно — они зафиксированы в `vercel.json`: фреймворк Vite, установка `npm ci`, сборка `npm run build`, выдача из `dist`. Версия Node (22.x) берётся из `engines` в `package.json`. Переменных окружения нет.
4. **Deploy.** Дальше каждый push в `main` публикуется автоматически, а ветки и pull request'ы получают preview-ссылки.

## Заявки с формы → Telegram

Форма отправляет JSON на `POST /api/lead` — это Vercel Function в `api/lead.js`.
Функция пишет владельцу в Telegram: тип заявки, имя, телефон, услуга, автомобиль,
дата, комментарий, время получения (МСК) и страница, с которой пришла заявка.

Нужны две переменные окружения в Vercel (Project → Settings → Environment Variables, Production):

| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | числовой id владельца; он должен один раз нажать «Start» у бота |

После добавления переменных нужен новый деплой. Пока их нет, функция отвечает 503,
а форма честно показывает ошибку с телефоном и Telegram.

Защита: только POST с Origin сайта, поле-ловушка и минимальное время заполнения для ботов,
серверная валидация, повторная отправка той же формы (или того же текста за 10 минут)
не создаёт дубль, не больше 3 заявок в час на номер и 30 за 10 минут на сайт
(Vercel Runtime Cache). «Вы записаны» показывается только после ответа `{ ok: true }`.

Локально: скопируйте `.env.example` в `.env.local` и запустите `npm run dev` —
`vite.config.js` направит `/api/lead` в ту же функцию.

## Структура

- `index.html` — вся разметка и тексты
- `src/style.css` — стили; палитра и шрифты в `:root`
- `src/main.js` — анимации и интерактив (лоадер, скролл, слайдер до/после, галерея, форма)
- `api/lead.js` — приём заявок и отправка в Telegram (Vercel Function)
- `vite.config.js` — только для dev: `/api/lead` в локальном сервере
